# Site Audit — AI-Operated Fixed-Scope Website Audit Service

**One-line description:** An AI-operated, fixed-scope site audit service that checks any public website for the most common SEO and technical problems and delivers a prioritized fix report.

## What it does

A fixed-scope automated audit that runs 8 checks against a site's homepage and produces a clear, plain-language report:

1. HTTP status check
2. HTTPS (or redirect to HTTPS)
3. `<title>` presence and length
4. Meta description presence and length
5. Mobile viewport meta tag
6. Images missing `alt` text
7. Time to first response
8. Exactly one `<h1>` on the page
